## 🎨 Theme Specification (Exact Match to Referral)

### Color Palette
```
Deep Navy:    #0B1A2D  (backgrounds, titles)
Teal:         #00839F  (headings, accents)
Bright Cyan:  #1D8DFF  (highlights, icons)
Gold:         #DFA12D  (accent strips, metrics)
White:        #FFFFFF  (cards, backgrounds)
Light Grey:   #F5F5F5  (alternating slides)
Dark Text:    #1F2937  (body copy)
```

### Typography
- **Font:** Segoe UI (Microsoft standard)
- **Titles:** 40-44pt Semibold, Navy
- **Headings:** 24-28pt Semibold, Teal  
- **Body:** 16-18pt Regular, Dark Text
- **Metrics:** 36-48pt Bold, Color-coded

✅ Diagonal geometric accent (Navy/Teal/Gold layers)
✅ Gold horizontal accent line
✅ Navy footer bar with white text
✅ Rounded cards with subtle shadows
✅ Fluent Design icons
✅ Generous whitespace
✅ Minimal text, maximum visual impact

## 🚀 How to Use This Package

### Option 1: Auto-Generate (Fastest - 5 min)
**On any computer with Python + internet:**
```bash
pip install python-pptx
python create_astra_ppt.py
```
**Output:** `ASTRA-Leadership-Review.pptx` ready to present!

---

### Option 2: Manual Build in PowerPoint (45 min)
1. Open Microsoft PowerPoint
2. Set up custom theme colors (see palette above)
3. Set Segoe UI as default font
4. Follow `ASTRA-Leadership-Review-Design-Spec.md` slide-by-slide
5. Use Insert → Shapes for cards, arrows
6. Use Insert → Icons for emojis (Fluent style)

---

### Option 3: Use Google Slides (Alternative)
1. Create new Google Slides presentation
2. Set theme colors (Tools → Theme builder)
3. Follow design spec to build slides
4. Download as PowerPoint (File → Download → .pptx)

---
