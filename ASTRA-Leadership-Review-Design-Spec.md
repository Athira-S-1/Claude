## 🎯 ANIMATION & TRANSITION GUIDELINES

### Slide Transitions
- **Between Slides:** Fade (0.3s duration)
- **Alternate:** Wipe from right (matches diagonal theme)

### On-Slide Animations
- **Cards:** Fade in + slight zoom (0.4s, sequential with 0.1s delay)
- **Workflow arrows:** Wipe right (0.3s, after card appears)
- **KPI numbers:** Morph/count-up effect (0.6s)
- **Text blocks:** Fade in (0.3s)

### Animation Sequence Example (Slide 2):
1. Title appears (0s)
2. Value proposition fades in (0.3s)
3. KPI cards appear left-to-right (0.6s, 0.7s, 0.8s, 0.9s)
4. Benefits fade in (1.2s)
5. Call-to-action appears (1.5s)

**Rule:** Keep animations subtle, professional, never distracting

## 📐 MASTER LAYOUT SPECIFICATIONS

### Margins & Grid
- **Top margin:** 0.5"
- **Side margins:** 0.5"
- **Bottom margin:** 0.5"
- **Grid:** 12-column, 0.75" gutters
- **Vertical rhythm:** 0.25" increments

### Card Specifications
- **Border radius:** 12px (rounded corners)
- **Shadow:** 0 2px 8px rgba(0,0,0,0.08)
- **Padding:** 0.2" all sides
- **Border width:** 1-3pt depending on emphasis

### Icon Guidelines
- **Size:** 48pt for primary, 24pt for secondary
- **Style:** Fluent Design System (Microsoft)
- **Color:** Match accent colors or Navy
- **Spacing:** 0.2" from text

### Typography Hierarchy
```
Level 1: Slide Title — 40-44pt, Semibold, Navy
Level 2: Section Heading — 24-28pt, Semibold, Teal
Level 3: Card Title — 16-18pt, Bold, Accent Color
Level 4: Body — 14-16pt, Regular, Dark Text
Level 5: Caption/Note — 11-12pt, Regular/Italic, Teal
Level 6: Metrics — 36-48pt, Bold, Accent Color
```

## 🎨 POWERPOINT IMPLEMENTATION GUIDE

### Step 1: Set Up Master Slides
1. Create custom theme with color palette
2. Set Segoe UI as default font
3. Create 3 master layouts:
   - **Layout A:** White background (Slides 1, 3, 5, 7, 9)
   - **Layout B:** Light grey background (Slides 2, 4, 6, 8, 10)
   - **Layout C:** Cover page with diagonal accent

### Step 2: Build Reusable Components
1. **KPI Card Template:** White fill, colored border, rounded corners
2. **Workflow Card Template:** Colored fill, white text, numbered circle
3. **Pain Point Card Template:** Colored fill, white text, badge circle
4. **Architecture Bar Template:** Colored fill, white text, full-width

### Step 3: Insert Content
